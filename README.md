# 🐍 Jogo da Cobrinha

Um jogo clássico da cobrinha implementado em **JavaScript puro**, com interface moderna e responsiva.

## 🎮 Como Jogar

### Controles
- **Setas do Teclado** ⬆️ ⬇️ ⬅️ ➡️ para mover a cobrinha
- **WASD** também funciona
- **Iniciar Jogo** - Comece a jogar
- **Pausar/Retomar** - Pause e retome o jogo
- **Reiniciar** - Resete o jogo para começar novamente

### Objetivo
- Coma as comidas vermelhas 🍎 para crescer e ganhar pontos
- Cada comida comida vale **10 pontos**
- A dificuldade aumenta gradualmente conforme você come mais
- Evite bater nas paredes e em você mesmo
- Tente bater seu recorde! 🏆

## 🌟 Recursos

✅ **Gameplay Clássico** - Mecânica tradicional da cobrinha
✅ **Sistema de Pontos** - Pontuação em tempo real e recorde salvo
✅ **Aumento de Dificuldade** - Velocidade aumenta conforme progride
✅ **Controles Responsivos** - Setas e WASD suportados
✅ **Interface Moderna** - Design limpo e intuitivo
✅ **Persistência de Dados** - Seu recorde é salvo localmente
✅ **Geração Aleatória de Comida** - Comida nunca aparece sobre a cobrinha

## 🛠️ Tecnologias Utilizadas

- **HTML5** - Estrutura
- **CSS3** - Estilização com gradientes e animações
- **JavaScript** - Lógica do jogo
- **Canvas API** - Renderização gráfica

## 🚀 Como Usar

1. Clone o repositório:
```bash
git clone https://github.com/Dangsoares/snake-game.git
cd snake-game
```

2. Abra o arquivo `index.html` no seu navegador
3. Clique em "Iniciar Jogo" e divirta-se! 🎉
